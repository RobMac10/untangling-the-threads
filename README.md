# The Story of Us — Untangling the Threads

Interactive family reading edition of the 48-page book compiled by Robin Truasheim (2025).

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
python3 -m http.server 8765
```

Then visit http://127.0.0.1:8765/

## Contents

Static HTML/CSS/JS. Book text and page images live under `assets/`.
The original PDF is at `assets/pdf/The-Story-of-Us-Untangling-the-Threads.pdf`.

## Note

This edition keeps the book’s wording. Body text is a proofread transcription of every page; family charts are shown as pictures.
No GitHub publish step is included until asked.
